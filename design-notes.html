Design notes: perception & mental models

This page documents, on purpose, where and why each principle was applied across the site — written for the HCI assignment, but honestly just good practice for any interface.

Gestalt principles

Proximity

On the enrollment form, personal-detail fields (name, email, phone, date of birth) sit inside one bordered group, and course/schedule fields sit inside a separate group. The border and shared background tell the eye these six fields are really two related sets, not six unrelated ones — without a single word of instruction.

Similarity

Every button on the site shares one of three consistent styles (.btn-primary, .btn-ghost, .btn-cta), and every icon shares the same stroke weight and line style. Once a person learns what one button or icon does, they can predict what a similar-looking one does elsewhere.

Continuity

The navigation bar reads left to right in one continuous line — logo, then pages, in a fixed order on every page — instead of being split across separate rows or corners. The eye follows it as a single path rather than re-scanning the page to find it.

Closure

The logo mark next to "Northfield" is a single arc with a deliberate gap — the stroke never actually closes into a circle, but the eye completes it anyway. It's the same effect the brief describes as "a logo formed by an incomplete circle still perceived as whole."

Figure-ground

The "Applications close soon" banner on the home page switches to a solid dark background with light, bold text — a deliberate break from the paper-colored page around it, so that one message reads as clearly in front of its background, not blended into it.

Visual hierarchy

Each page has at most one gold • CTA button (Reserve your seat, Start enrollment, Submit enrollment) — the single action that page most wants a visitor to take. Every other button uses a quieter ink or outline style, so the gold button is never competing with a same-weight neighbor. Color and contrast are doing the ranking, not size alone.

Mental model alignment

Icons are only used where they match an existing real-world idea: a folder for the course catalog, a calendar for scheduling, a trash can for the destructive "clear all" action on the admin page, and a check mark for a completed enrollment. Buttons behave the way their label promises — "Submit enrollment" submits and moves forward, "Clear all" asks for confirmation before deleting anything, and every link goes exactly where its text says it will. Nothing here tries to be clever at the expense of being predictable.

Reflection

This design uses proximity to group the enrollment form's personal and course fields so the form reads as two short decisions instead of one long list, and similarity across buttons and icons so a person only has to learn each pattern once. Continuity in the navigation bar and closure in the logo make the interface feel already familiar on first glance, while the dark figure-ground banner and single gold call-to-action button make sure the one action that matters — enrolling — is never in doubt. Together these choices reduce how much a first-time visitor has to think about the interface itself, leaving their attention for the actual decision: which course to take. Building it also showed how much of "obvious" design is really just consistent repetition of a small number of visual rules. The biggest lesson was that hierarchy only works if it's used sparingly — the moment a second element competes for the same gold-button attention, neither one wins.
